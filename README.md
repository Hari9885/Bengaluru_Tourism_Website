# 🌿 Bengaluru Tourism Website

> A clean, responsive static tourism website showcasing the history, nature, culture, religion, commerce, and administrative landmarks of Bengaluru, Karnataka.

## 📖 About the Project

**Bengaluru Tourism** is a simple, responsive tourism portal designed to introduce visitors to different sides of Bengaluru and its surrounding attractions.

The website provides a visually engaging homepage with an automatic image carousel and separate category pages for exploring:

* 🏛️ Historic Bengaluru
* 🏢 Administrative Bengaluru
* 🌿 Wildlife & Nature
* 🛕 Religious Bengaluru
* 🛍️ Commercial Bengaluru
* 🎭 Art & Culture

The project is built entirely with **HTML and CSS**, making it lightweight, easy to understand, and simple to deploy without a backend or database.

---

## ✨ Features

### 🖼️ Automatic Hero Carousel

The homepage includes a full-width image carousel highlighting Bengaluru and Karnataka attractions.

The carousel is implemented using **CSS animations**, so no JavaScript library is required.

### 🧭 Category-Based Navigation

A persistent navigation bar provides quick access to each tourism category.

### 📱 Responsive Design

The layout adapts to different screen sizes, including:

* Desktop screens
* Tablets
* Mobile devices

Responsive breakpoints are implemented using CSS media queries.

### 🎨 Clean Visual Design

The website uses a nature-inspired visual theme with:

* Deep green backgrounds
* Gold accent elements
* Card-based layouts
* Image overlays
* Responsive typography
* Subtle shadows and hover effects

### ♿ Accessible Image Descriptions

Images include descriptive `alt` text to improve accessibility and provide context when images cannot be displayed.

### 🧩 Easily Extensible

Each tourism category has its own HTML page, making it easy to add:

* Tourist attractions
* Images
* Location information
* Opening hours
* Historical information
* Travel tips
* Maps
* Reviews
* Additional tourism categories

| Technology                   | Purpose                                         |
| ---------------------------- | ----------------------------------------------- |
| **HTML5**                    | Website structure and content                   |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Navigate to the project

```bash
cd Bengaluru_Tourism_Website
```

### 3. Open the website

Simply open:

```text
index.html
```

in any modern web browser.

Alternatively, use **VS Code Live Server** or any local HTTP server for development.

For example:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
